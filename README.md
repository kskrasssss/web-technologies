## 💻 Улюблені мови програмування та стек технологій

### 🔤 Основні мови програмування

- **Python** — основна мова для Data Science, написання скриптів та аналізу даних.
- **C++** — об'єктно-орієнтоване програмування, робота з пам'яттю та низькорівневі алгоритми.
- **C#** — вивчення .NET-платформи та розробка програмних систем.

### 📊 Data Science та математичний аналіз

- **NumPy & Pandas** — робота з масивами, очищення та аналіз датасетів.
- **SciPy & Matplotlib** — наукові обчислення, математичне моделювання та візуалізація даних.

### 🛠️ Інструменти розробки, CI/CD та UI/UX

- **Git & GitHub** — версіонування коду, SSH-авторизація, робота з гілками та Pull Request.
- **VS Code** — основне IDE середовище.
- **Figma** — проєктування інтерфейсів, UI/UX дизайн, робота з дизайн-системами.
